# Stellar Burgers

Stellar Burgers — это интерактивное приложение для создания космических бургеров с авторизацией, историей заказов и лентой заказов.

## Функционал
1) Конструктор бургеров
    - Перетаскивание ингредиентов, выбор булки, динамический подсчёт стоимости.
    - Оформление заказа только для авторизованных пользователей.
    - Модальное окно с деталями заказа.
2) Лента заказов
    - Просмотр всех заказов в реальном времени.
    - Модальное окно с деталями заказа.
3) Профиль пользователя
    - Просмотр и редактирование имени, email и пароля.
    - История заказов пользователя с подробностями по каждому заказу.
    - Безопасный выход из аккаунта.
4) Аутентификация
    - Регистрация, вход, восстановление и сброс пароля.
    - Защищённые роуты для профиля и истории заказов.

##  Технологии
1) React + TypeScript
2) Redux Toolkit 
3) React Router
4) WebSocket для ленты заказов
4) CSS Modules для стилизации

## Инструкция по запуску проекта
1) Установите зависимости
    `npm install`
2) Запустите проект:
    `npm start`
3) Откройте в браузере http://localhost:4000
